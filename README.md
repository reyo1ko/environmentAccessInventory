# Access Note — アカウント管理台帳テンプレート

環境ごとの接続経路と複数アカウントを、1つのHTMLで管理するテンプレートです。
このリポジトリに含まれる環境名・ホスト名・IP・ログイン情報は、すべて架空のサンプルです。

## ダウンロードして使う

1. GitHubの **Code → Download ZIP** からダウンロードします。
2. ZIPを展開し、`index.html` をEdgeまたはChromeで開きます。
3. 「編集」をONにして、環境や接続先を自分用に編集します。

インストール、サーバー、インターネット接続は不要です。利用するだけなら `index.html` の1ファイルで動作します。
GitHub Pagesへの公開設定は不要です。

## できること

- 全環境を1画面に表示し、環境単位で折りたたみ
- 接続先が1つなら横、複数なら下に並べ、経路を線と矢印で表示
- 各環境の「＋ 接続先を追加」から登録し、接続元は後から指定
- ドラッグ＆ドロップによる接続元変更と、直前の移動の取り消し
- 1つの接続先に複数のアカウント・ログイン名・パスワードを登録
- ホスト名、IP、各アカウントのログイン名などを個別にコピー
- JSONによるバックアップ・復元

接続やログインを自動実行する機能はありません。
詳しい操作は [使い方.txt](使い方.txt) を参照してください。

## テンプレートと利用者データの扱い

- GitHubに置くHTMLはサンプル入りのテンプレートです。
- ダウンロード後の入力は、利用者のブラウザの `localStorage` に保存します。
- 通常の入力操作でHTML自体やGitHubのファイルが書き換わることはありません。
- 外部へのデータ送信や外部ライブラリの読み込みは行いません。
- 保存済みの入力内容を、サンプルで自動上書きする処理はありません。
- テンプレート用の保存キーは `access-note-template-v1` です。開発中の旧版の保存領域とは別です。
- 同じブラウザで複数の台帳を使うと、開き方によって保存領域を共有する場合があります。

HTMLをコピーするだけでは入力済みデータは移行しません。別PC・別ブラウザへの移行やファイルの移動前には「バックアップ」を保存し、移行先で「復元」してください。復元は現在の台帳を置き換えます。

保存データとバックアップJSONは暗号化していません。利用するPCとブラウザへのアクセスを管理し、バックアップは個別に保管してください。ブラウザの保存データを消すと入力内容も失われます。

## GitHubに登録するファイル

- `index.html` — 架空のサンプル入りアプリ
- `README.md` — 導入・保存方式の説明
- `使い方.txt` — 操作説明
- `.gitignore` — 利用者データなどの除外設定
- `checks/` — サンプルと主要操作の自動チェック
- `.github/workflows/check.yml` — GitHub Actionsのチェック設定

実際のバックアップJSON、個人用データ、認証情報を含む画像は登録しないでください。
`.gitignore` はバックアップJSONやローカル作業フォルダを除外しますが、GitHubの画面から手動アップロードする際は、自分で対象ファイルを選別してください。

## 開発時のチェック

Node.js 22以降で、次を実行します。追加パッケージのインストールは不要です。

```sh
node checks/verify.cjs
```

経路変更、複数アカウントの保存・コピー、バックアップ形式、テンプレートの初期表示、再読み込みで編集内容を保持することを確認します。GitHubへのpush・pull request時にも同じチェックを実行します。
